# 动态候选记忆（.agent/memory/）

本目录是 Nornia 项目的动态记忆层，保存 Agent 在工作过程中自动发现、尚未验证或临时的信息。

## 原则

- `AGENTS.md`（仓库根）是权威项目记忆（Single Source of Truth），只保存稳定、明确、经人工确认或充分验证的项目事实与规则。
- 本目录内容默认视为“候选事实”，可信度低于 AGENTS.md。
- Agent 自动发现的信息（项目历史、任务上下文、临时结论、自动提取的事实、经验、推测）应首先写入这里，不直接写 AGENTS.md。
- 只有当某项信息经过代码、文档、测试结果、多次观察或用户确认，且具有长期价值时，才将其提升（promote）到 AGENTS.md，并从本目录移除或标记为已提升。

## 记忆优先级

用户当前明确指令 > 当前任务上下文 > AGENTS.md > 已验证动态记忆 > 普通动态记忆 > Agent 推断

## 冲突处理

当不同记忆来源发生冲突时，不应静默选择旧信息。应优先采用更高优先级、更明确、更新且可验证的信息，并在必要时更新或废弃已失效的动态记忆。

## 记录约定

- 每个主题一个文件，建议命名 `YYYYMMDD-<topic>.md`；持续追加类记录可用 `.jsonl`。
- 每条记录注明：发现时间、来源（文件/命令/对话）、验证状态（未验证/已验证/已废弃）、是否适合提升到 AGENTS.md。
- AGENTS.md 若持续增长（建议单文件 2–8 KB，上限 10–15 KB），应优先拆分为 `docs/` 下的详细文档，而不是无限扩充根文件。
